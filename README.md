# SwipeCart
A mini Flipkart-inspired e-commerce demo.

## Project Scope
Build a professional, clean, responsive e-commerce web application with a dedicated "Swipe to Shop" feature.

## Tech Stack
- **Frontend (/client):** React, Vite, JavaScript, Tailwind CSS, Axios
- **Backend (/server):** Node.js, Express, MongoDB, Mongoose
- **Authentication:** JWT & bcrypt
- **Payment:** Cash on Delivery (COD) only

## Repository Structure
- `/client`: Frontend source code
- `/server`: Backend source code
- `/docs`: Project documentation
